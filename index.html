How It Works

Enter a password to calculate its character pool size and a character-pool entropy estimate in bits. The score uses length x log2(character pool size) and maps the result to a strength band.

It assumes characters are selected uniformly from the detected pool, so it is an upper-bound estimate. It is not measured entropy and does not predict real-world cracking time. The tool also flags a few obvious repeated, common, or sequence patterns.

Frequently Asked Questions

What does the bit score mean?

Password Entropy calculates length x log2(character pool size) from the character classes present. It maps that character-pool estimate to a strength band; it is not measured entropy.

Does this predict real-world cracking time?

No. Password Entropy reports a character-pool estimate and strength band. It does not predict real-world cracking time or account for password choice, breach data, hash algorithms, attacker hardware, or rate limits.

Is my data private and secure?

Yes. All operations run 100% inside your local web browser using client-side JavaScript. No text, tokens, code, or personal data are ever uploaded to an external server.

Can I run this tool completely offline?

Yes. You can install the packaged Manifest V3 Chrome Extension version or save this standalone HTML page locally to use without an internet connection.
